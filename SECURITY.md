# Security Policy

## Reporting a vulnerability

Please do not publish credentials, tokens, complete provider responses or other account data in a public issue.

Use GitHub's private vulnerability reporting feature in the repository's **Security** tab. Include the affected version, a concise reproduction and sanitized logs where possible.

## Sensitive data

AI Taskbar Usage reads existing local Claude Code and Codex authentication files only to request the associated usage information. Tokens must never be displayed, logged, committed, attached to an issue or included in diagnostics.
